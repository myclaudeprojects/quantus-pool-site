How the pool works

Honest path from GPU to provisional credit — then claim after launch.

Register

Submit your wallet address. You get a miner ID + API key for heartbeats from the one-click package or your own miner.

Download & mine

Pass the Argus hold check (or pre-token bypass). Installer sends hash to the operator wormhole; you report hashrate here.

Claim later

When CLAIMS_OPEN flips true, request payout against your provisional credit. Locked by default today.

Included

  • Miner registration + API key
  • Heartbeat hashrate / share ledger (SQLite)
  • Gated Windows one-click zip download
  • Argus paywall stub (live when CA is set)
  • Claims API schema ready, gated off

Not claimed

  • No instant QTC to your wallet
  • No guarantee of block attribution
  • Token not launched — hold check is stubbed
  • Electricity and hardware wear are yours
