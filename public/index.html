How pool shares work

No paywall — anyone can download and mine. Mining is required for pool eligibility: no recent heartbeat → weight = 0 → 0% of the pool mining pot, even with a large Arc bag. Arc QTC ≠ L1 Quantus.

1. Download free

Open Windows miner — no token gate. Buying Arc QTC is optional for mining; it only sets your bag size for share weight.

2. Mine to be eligible

Keep a fresh heartbeat (“connected”). Holders who don’t mine get 0% of the mined pot. Connected is the gate.

3. Convex weight

While mining: weight = holdings1.5. Bigger bags get more than linear advantage. Shares sum to 100% of the pool mining pot.

Locked formula

if not mining (no recent heartbeat) → weighti = 0
if mining → weighti = Arc_QTC_holdingsi1.5
pool_sharei = weighti / Σ weightj
claimi = pool_sharei × mined_L1_QTC_in_pool

Claim % is of the pool mining pot (whatever L1 Quantus the pool has mined) — not % of the 21M L1 chain max (context only). Extra ×1.5 connected boost dropped (redundant with the mining gate). API: GET /api/rewards/formula.
